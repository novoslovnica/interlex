# Публичные этимологические свидетельства ЦС Словаря

`GET /api/public/cs/proto/{id}` отдаёт только публичные поля proto-статьи: id, lemma, body, sourceUrl, morphemes и SHA-256 текста. Ключ не нужен; серверный секрет не передаётся мобильному клиенту. Есть CORS и лимит 120 запросов/мин на IP процесса, дополнительно к общей политике proxy. Отказ базы даёт 503 и не мешает основному словарю typikon-web.

Typikon-web владеет проверенной связью с церковнославянской лексемой/значением. Interlex владеет содержанием proto-статьи и библиографией. Клиент сверяет bodySha256 с проверенной редакцией и сообщает об изменении текста; это не замена повторной редакторской проверки.

Экспорт семантического справочника только для чтения:

```sh
python3 scripts/export-cs-semantics.py \
  --reference scripts/python/.venv/lib/python3.14/site-packages/ruwordnet/static/ruwordnet.db \
  --out /absolute/path/cs-ruwordnet.json
```

Путь к установленному RuWordNet может отличаться. Экспорт содержит внешние синсеты, русские единицы, явные отношения антонимии и отпечаток справочника. Он не читает межславянские semantic_relations и не меняет interlex.db/historical.db. Обогащение церковнославянских значений и редакторские решения находятся в typikon-web.

Проверки: `npx vitest run lib/publicApi/csProto.test.ts`, `npm run typecheck:gate`. Выкладка — штатный release.sh без загрузки снимков баз; новая ручка не требует миграции или записи в базы.
