# Главная страница и единая конфигурация баз — 2026-10-18

## Главная страница

Раньше каждый запрос главной делал два GROUP BY lemma по всему корпусу,
сортировку частот и регрессию Ципфа. Дополнительно считались предложения и
уникальные леммы, которые на странице вообще не использовались.

Теперь `app/main/stats.ts` кэширует числовые показатели на 300 секунд через
Next Data Cache. Локализованные подписи, cookies и сессии остаются за пределами
кэша. Используется существующий `corpus_config.zipf_alpha`, записываемый
`computeLexiconFrequencies`: даже холодный запрос не группирует CorpusToken.
Пустой/некорректный коэффициент отображается как «—», без скрытого тяжёлого
пересчёта. Значение обновляется штатным пересчётом частотности, а не посещением
главной; это коэффициент распределения частот лексем (wordSlug), как в общей
системе частотности, вместо прежнего отдельного распределения строк lemma.

Счётчики лексем и значений ограничены публичным словарём. Показатель coverage
сохраняет прежний смысл: доля всех токенов с wordSlug, включая пунктуацию в
знаменателе. Он не является оценкой правильности лемм/POS/граммем. Изменение этой
метрики требует отдельного решения, чтобы не смешивать ускорение с оценкой
лингвистического качества. После изменений данных счётчики могут отставать
до пяти минут; коэффициент Ципфа — до очередного пересчёта частотности.

Случайное слово раньше выбиралось без isPublic. Теперь max-id, основной выбор
и fallback фильтруют isPublic=true, а выбор диапазона сортируется по id.
Пустой публичный словарь или удаление слов между запросами возвращают null;
виджет условно скрывается вместо разыменования `randomWord!`.

## Конфигурация БД и CI

`lib/databaseUrls.ts` — общий источник URL для `lib/prisma.ts` и
`prisma.config.ts`. Явные *_DATABASE_URL сохраняются. Без них файлы всех пяти
баз находятся в текущем корне проекта, включая interlex.db вместо app.db;
вариантов prisma/*.db больше нет. Сам helper не открывает и не создаёт файлы.

Prisma CLI больше не вызывает env() перед fallback: тот выбрасывал исключение
при отсутствии переменной, и запасное значение не выполнялось. Это важно для
чистой CI-среды без .env. Workflow генерирует также historical-клиент, который
уже импортируется общим модулем Prisma. README отражает пять клиентов и баз,
реальные команды, реестр миграций и отдельные аккаунты разработки.

## Проверка

Тесты проверяют числовую статистику без GROUP BY, настройки общего кэша,
отсутствующий/невалидный коэффициент, пустой корпус, public-фильтры всех путей
выбора случайного слова и единые пути пяти баз. Конфигурация Prisma дополнительно
загружается без .env и *_DATABASE_URL из временного каталога. Рабочие БД в этой
задаче не менялись; тяжёлые запросы корпуса на локальных данных не запускались.
