AGENTS.md). Продакшен-запрос (`createQueryWordsByBase` в `analyzer-factory.ts`) не потребовал изменений — просто получает более широкий список `bases`. Открыто: перепрогнать `scripts/db/2026-07-28-reanalyze-all-documents.ts` на реальном корпусе, чтобы фактически переразметить "sut"-вхождения (2325+) — не сделано в рамках этой сессии, отдельное решение (трогает продовые данные).
